## Important for agents

- There is **no publicly callable Erie Insurance API**. No machine-readable contract of any kind is
  published on the open web.
- There is **no Erie developer portal**. `developer.erieinsurance.com`, `developers.erieinsurance.com`,
  `api.erieinsurance.com`, `apis.erieinsurance.com`, `partner.erieinsurance.com` and
  `partners.erieinsurance.com` all return NXDOMAIN to public DNS.
- `www.erieinsurance.com` serves **no** `/.well-known/` discovery documents: `security.txt`,
  `openid-configuration`, `oauth-authorization-server`, `oauth-protected-resource`, `api-catalog`,
  `ai-plugin.json`, `mcp.json`, `agent-card.json` and `agent.json` all return 404. A negative-control
  path also returns 404, so those 404s are trustworthy.
- `services.erieinsurance.com` is a live, publicly-reachable **SOAP gateway** — an API surface exists —
  but it publishes no contract. It answers HTTP 500 with a byte-identical 259-byte SOAP `env:Fault`
  ("Internal Error (from client)") for **every** path, including `?wsdl`, `?singleWsdl` and a control
  path that cannot exist. Do not treat any response from that host as a document.
- There is **no** Erie MCP server, **no** A2A agent card, **no** public status page, **no** published
  rate limits and **no** API pricing or plans.
- There is **no** Erie Insurance GitHub organization and **no** first-party SDK in npm, PyPI, RubyGems,
  crates.io, Maven Central or NuGet.
- Machine access to Erie is a **business relationship**, not a self-serve product: it runs through an
  independent-agency appointment and the agent login, or through industry exchange intermediaries
  (ACORD/IVANS-style downloads and real-time rating inside agency management systems). An agent cannot
  complete it.
